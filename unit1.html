Unit 1
Primitives and
Basic Methods
Students learn Java primitive data types, variables, arithmetic expressions, and coordinate-based drawing through Processing's built-in methods. The unit builds toward reading documentation independently and using keyboard and mouse events to create interactive programs.
Activities
01
Algorithms
on Paper
Students draw robots freehand and then on grids, discovering how coordinate systems give precise addresses to every point on a canvas before writing a single line of code.
02
Shape Functions
& Docs
Grid designs get translated into code using Processing's shape methods. Students read the reference documentation independently to discover functions beyond rect() and ellipse().
03
Data Types
& Output
int, float, and String are introduced through print() and println() experiments. Students use output statements to debug coordinate placement in their robot sketches.
04
Variables
& Input
Variables store robot position and drive animation. Students wire up keyboard and mouse events, then use the modulo operator to make objects wrap around the canvas.
05
Robot Showcase
& Peer Review
Final interactive robots are shared in a class gallery walk. Students give feedback using technical vocabulary and evaluate design choices and code quality in peers' sketches.
