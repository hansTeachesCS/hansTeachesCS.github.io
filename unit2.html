Unit 2
Object Basics
Students extend their Java toolkit by diving into the String and Math classes, learning to process text character-by-character and design helper methods with proper signatures and return types. Randomness and collision detection through the Math class anchor the second half of the unit, pushing students to apply documentation reading independently throughout.
Activities
01
Caesar
Cipher
Using Scanner for input and substring() in a loop, students encrypt messages letter-by-letter by converting characters to ASCII values, applying a shift, and casting back to char.
02
Method Design
& Refactoring
Students refactor their Caesar cipher into clean helper methods, applying the DRY principle and practicing correct method signatures with meaningful parameter types and return types.
03
Name Tag
Project
String methods (substring, toUpperCase, concatenation) and conditionals combine in a visual Processing program. Methods like formatName and getTextColor produce dynamic, data-driven output.
04
Clicking
Game
Math.random() spawns targets at random positions with random sizes and weighted types. The distance formula using Math.sqrt() and Math.pow() determines whether a click lands inside a target.
05
Game States
& Scoring
Students wire up a full game loop — title screen, gameplay, and game-over state — managed by a state variable. Frame-based timing controls target spawning and a score variable updates on every successful click.
