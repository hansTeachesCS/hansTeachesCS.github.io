Unit 3
Boolean Expressions
and If Statements
Students put boolean logic to work building a traffic simulation where animated cars respond to a working traffic light, with speed controlled by mouse position. A pedestrian button raises the complexity, giving students a real reason to study De Morgan's Law and compound boolean expressions.
Activities
01
CodingBat &
Boolean Methods
Students write multiple solutions to the same string problem, compare trade-offs between approaches, and stress-test each solution against edge cases using boolean methods with proper return statements.
02
Traffic Light
Simulation
if/else chains map mouse position to car speed, translating real-world rules — stop on red, slow on yellow, go on green — into conditional logic with precise boundary conditions.
03
De Morgan's
Law
Students rewrite negated compound boolean expressions into equivalent forms, verify logical equivalence through testing, and practice choosing the most readable version of a condition.
04
Day/Night
Cycle
A boolean state variable and frameCount % 600 create a day/night cycle that toggles scene behavior every 5 seconds, combining mouse position, time, and button state into one cohesive conditional system.
05
Pedestrian Button
& Peer Review
A pedestrian button introduces compound boolean conditions that override traffic light logic to stop the car. Students then review peers' code against a rubric, tracing conditionals to verify correct behavior.
