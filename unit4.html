Unit 4
Iteration
Students learn for loops and while loops by building toward a personal identity flag where exactly 50 stars must be placed using nested loops in any arrangement of their choosing. CodingBat string problems run alongside, reinforcing accumulation patterns, boolean flags, and short-circuit logic.
Activities
01
Loop
Fundamentals
For loop syntax — initialization, condition, increment — and converting between for and while loops. Students practice counting up, counting down, and skip counting to position objects at regular intervals.
02
Nested Loops
& Patterns
Students find the mathematical relationship between row numbers and object quantities, then build grids, pyramids, and checkerboards using nested loops and the modulo operator to alternate behavior between rows.
03
CodingBat
String Algorithms
Accumulation patterns, boolean flag variables, and short-circuit logic applied to string problems. Nested loops tackle multi-character pattern detection with careful attention to index out-of-bounds conditions.
04
Identity
Flag
Students design a flag on paper — 50 stars in any arrangement plus personal symbols — then translate it to Processing using nested loops, positional formulas, and intentional color and layout choices that reflect their identity.
05
Flag
Showcase
Students present their flags to the class, explaining the loop logic behind their star arrangements and the personal meaning in their design choices, celebrating the intersection of identity, culture, and code.
