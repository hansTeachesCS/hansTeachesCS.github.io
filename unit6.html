Unit 6
Writing Classes
Students make the leap from procedural to object-oriented programming, rewriting familiar projects as class-based designs with instance variables, constructors, and methods. Arrays of objects replace the parallel arrays of Unit 5, and the unit closes with a crowd-sourced Candy class that sets up the ArrayList project ahead.
Activities
01
OOP
Confetti
The Unit 5 parallel-array confetti gets rewritten as a Confetti class with instance variables, a constructor, and display() and update() methods. An array of objects scales the animation up cleanly.
02
OOP
Whack-a-Mole
The clicking game is refactored into a Mole class with a checkClick() boolean method, an isBomb flag set by Math.random(), and an array of Mole objects managed with both regular and enhanced for loops.
03
Generative Art
& AP FRQ
Students refactor a generative art sketch into OOP design and exchange peer feedback on class structure. A past AP Exam Scoreboard question reinforces writing constructors, void methods that modify state, and formatted String output.
04
Candy
Design
Each student draws a candy that fits in a 50x50px boundary using a drawCandy(int x, int y) method, then shares their design and specs in a class Google Doc to crowd-source a shared candy library.
05
Candy
Class
Students write a Candy class with at least 4 instance variables, a constructor, and getter and setter methods. Creating multiple Candy objects in a sketch previews the ArrayList project coming in Unit 7.
