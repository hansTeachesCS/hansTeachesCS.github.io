Unit 7
ArrayLists
Students put ArrayLists to work in two large-scale projects: a CandyBox store where add() and remove() respond to real mouse events, and a data visualization suite that reads text files with Scanner, parses records into custom classes, and maps multi-year temperature and restaurant datasets as interactive heatmaps. Along the way, students master ArrayList traversal patterns including forward and reverse removal, boolean flag deduplication, and nested loops comparing two collections.
Activities
01
CandyBox
Store
An array of template Candy objects serves as the menu while an ArrayList represents the cart. mousePressed() detects clicks on menu items, add() and remove() update the cart, and a loop calculates the running total price displayed on screen.
02
Reading
Text Files
Scanner reads a text file line by line using hasNextLine() and nextLine(). Students use indexOf() and substring() to extract fields from each line and Integer.parseInt() to convert numeric strings, building toward a full data pipeline.
03
Temperature
Heatmaps
A DayRecord class holds month, day, and temp parsed from real datasets. Students populate an ArrayList, find min and max with a traversal, then draw a color-mapped grid of rectangles, one per record, using % and / to wrap rows.
04
NYT Restaurant
Data
CSV lines are split() into fields and passed into a Restaurant constructor. Students build separate ArrayList<Restaurant> collections for 2024 and 2025 datasets, then write nested for-each loops to compare rankings and answer a self-chosen investigation question.
05
AP FRQ
Practice
Boolean flag variables and nested loops tackle duplicate detection across ArrayLists. The 2023 AP Writing a Class FRQ reinforces constructors, getters, and the full object lifecycle with real scoring criteria.
