Unit 8
2D Arrays
Students learn 2D array syntax by building Conway's Game of Life, designing a Cell class, refactoring into a Grid class with a neighbor-counting algorithm, and implementing the four rules of Life using a temporary array to avoid read/write conflicts. They then apply nested loop traversal to a Parking Lot project, writing algorithms that find the maximum value and sum across rows, columns, and diagonals using index arithmetic like r == c and r + c == size - 1.
Activities
01
Game of Life:
Cell & Grid
A Cell class stores position and alive/dead state, set by passing a percent-chance value into the constructor with Math.random(). Nested loops fill a 2D array with Cell objects and a Grid class is introduced to manage the array, a generation counter, and population tracking.
02
Game of Life:
Next Generation
countNeighbors() iterates over all dr/dc offsets from {-1, 0, 1} with bounds checking to avoid ArrayIndexOutOfBoundsException. nextGeneration() allocates a temporary Cell[][] next array, applies all four rules of Life using the neighbor count, then replaces world with next.
03
Parking Lot:
Max Traversal
A Car class with three instance variables is stored in a square Car[][] grid inside a ParkingLot constructor. Students scan the full 2D array row by row to locate the single highest-value car, tracking both the max value and its row and column position as they traverse.
04
Parking Lot:
Row/Column Sums
Nested loops accumulate totals across individual rows and columns to find the richest row or column. Students extend the same logic to diagonals, using the index relationships r == c for the main diagonal and r + c == size - 1 for the anti-diagonal.
05
2D Patterns
& AP FRQ
Students use arithmetic on r and c to produce checkerboard, diagonal, and region patterns in a lights[][] grid. A 2D boolean array populated with Math.random() and a column-traversal method reinforce the unit, alongside AP FRQ practice on 2D array problems.
