Unit 9
Recursion
Students build intuition for recursion by tracing arithmetic and string methods by hand, identifying base cases and mapping the full call stack before writing a single line of code. They then move to the Processing canvas where a recursive branch() method grows fractal trees, and students explore how angle, depth, and randomness produce everything from rigid geometric shapes to organic canopies.
Activities
01
Tracing &
Call Stacks
Students identify the base case and recursive case in a series of methods, then trace each call by hand, writing out parameter values at every level until the base case is reached. They explain what breaks when the base case is missing or unreachable.
02
Arithmetic
Recursion
Recursive methods that count digits, compute sums, and raise numbers to powers. Students predict output by tracing whether work happens before or after the recursive call, building a mental model of the call stack unwinding on the way back up.
03
String
Recursion
Recursive methods that reverse a string, check for palindromes, and count target characters. The string parameter shrinks with each call, and students connect the direction of printing output to whether the recursive call comes first or last.
04
Fractal Trees:
Branches
A branch(len, angle) method in Processing draws a line, then calls itself twice with a shorter length and offset angle using pushMatrix() and popMatrix() to save and restore canvas state. The base case stops recursion when the branch length falls below a minimum threshold.
05
Fractal Trees:
Variations
Students vary branching angle, number of recursive calls, and color by depth to produce different tree structures. Adding Math.random() to length and angle at each level transforms geometric symmetry into organic canopies, with mouseX and mouseY used to control parameters interactively.
